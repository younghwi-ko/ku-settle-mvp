# Supabase 통합 테스트 대기 목록

이 문서의 항목은 이메일 제한이 해제되고 전용 실제 인증 사용자를 준비한 뒤 실행한다. 현재는 모두 **보류**이며 통과로 간주하지 않는다.

- [ ] 보류 — 실제 `@korea.ac.kr` OTP 수신
- [ ] 보류 — 잘못된 도메인 가입 거부
- [ ] 보류 — 사용자 A·B의 profile 격리
- [ ] 보류 — 사용자 A·B의 progress 격리
- [ ] 보류 — 다른 사용자 상품 수정·삭제 차단
- [ ] 보류 — 세션 복원
- [ ] 보류 — Guest 데이터 import
- [ ] 보류 — 중복 import 방지
- [ ] 보류 — 계정 삭제
- [ ] 보류 — Marketplace 상품 cascade 삭제 및 삭제 후 기존 세션 접근 차단
- [ ] 보류 — 영어·한국어·일본어·중국어 OTP 이메일 수신

## 실행 전 안전 조건

- 개발 프로젝트 `ku-settle-dev`에서만 실행한다.
- 두 테스트 계정의 이메일, OTP, JWT 또는 기타 비밀값을 문서·Git·채팅에 기록하지 않는다.
- 실제 이메일 전송과 사용자 생성은 테스트 실행 직전에 별도 승인을 받는다.
